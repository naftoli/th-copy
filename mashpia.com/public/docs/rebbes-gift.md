# Rebbe's Gift

The Rebbe's Gift section manages the Bal Peh (by-heart memorization) program and the Rebbe's Birthday Gift campaign. Soldiers learn Tanya and Mishna by heart and their totals are submitted as a collective birthday gift to the Rebbe.

## Chayol Pledge Card (`/bp/pledge_cards.php`)

**Access:** BC

**Purpose:** Print individual pledge cards for each soldier showing their historical Tanya and Mishna line totals by year and grade. Used as part of the Rebbe's Birthday Gift initiative.

### What's Shown Per Card (one card per student, one page each)

- School name, grade, student name
- **Highest Tanya lines** achieved in any year
- **Highest Mishna lines** achieved in any year
- A **year-by-year table** showing Tanya and Mishna lines per grade level, going back to when the student started

### How to Use

1. Open the page — cards are automatically generated for all students
2. Click Print (Ctrl+P / Cmd+P)
3. Distribute cards to students

> Cards include a printed header and footer graphic. Pre-1st grade students receive a simplified card without the historical table.

> The page includes data from all years **prior** to the current year.

## Class Pledge Card (`/bp/classPledge.php`)

**Access:** BC

**Purpose:** Print a class-level pledge summary grid for the Rebbe's Birthday campaign — a single page per class showing all students' learning totals.

### What's Shown Per Class Page

- School name, class/grade
- A **grid** where:
  - Each **row** is a student
  - Each **column** is a year (from approximately 5775 to last year)
  - Split into **Tanya lines** and **Mishna lines** column groups
- A **totals row** at the bottom summing each year's column

### How to Use

1. Open the page — grids are automatically generated for all classes
2. Print (landscape orientation recommended for wide grids)

> All students in the school are included (registered and unregistered). Data covers all years prior to the current year.
