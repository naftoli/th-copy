# Overview & Getting Started

## What Is This Platform?

The Tzivos Hashem management platform is used by school administrators, teachers, and Headquarters staff to manage all aspects of the Tzivos Hashem youth program — from registering children and tracking missions, to managing the rewards store, running competitions, and generating reports.

---

## Key Terminology

| Term | Meaning |
|------|---------|
| **Soldier** | A child enrolled in the Tzivos Hashem program |
| **Platoon** | A class or grade level within a school |
| **Base** | A school or local Tzivos Hashem branch |
| **Institution** | An umbrella organization overseeing multiple bases |
| **Miles** | Reward points that soldiers earn by completing missions and spend in the store |
| **Mission** | A task or activity that soldiers complete (daily, weekly, Shabbos, or subject-based) |
| **Campaign / Subject** | A category of missions (e.g., Torah, Mitzvos, Shabbos) |
| **Medal** | An achievement earned by completing a set of subject missions |
| **Rank** | A military-style title (Private → General) earned by accumulating medals |
| **Serial Number** | Each soldier's unique ID number (format: 7xxxxxx) |
| **CTH** | Chayolei Tzivos Hashem — enrollment in the main program |
| **Hebrew Year** | The system uses Hebrew calendar years (e.g., 5784, 5785) |

## User Types

There are four types of admin accounts:

### HQ — Headquarters
- Full access to all bases, institutions, and soldiers in the entire system
- Can access all modules and all reports
- Can create prize templates, set global settings, and manage all bases

### INST — Institution Manager
- Manages multiple bases that belong to one institution/umbrella organization
- Access is filtered to bases within their institution
- Full access to all modules enabled for their institution

### BC — Base Commander
- Manages a single school/base
- Access is limited to soldiers, platoons, and staff at their base
- Module access depends on what the base has subscribed to

### TEACHER
- Manages a single platoon (class)
- Access limited to students in their specific class
- Can mark missions, manage orders, and print achievement cards
- Cannot access most reports or admin settings

## Modules

The platform is modular — bases subscribe to features they need. The available modules are:

| Module | What It Enables |
|--------|----------------|
| **Chayolei (CTH)** | Main program: ranks, medals, missions, registration |
| **Rewards** | Rewards store with miles, prizes, and orders |
| **Chidon** | Chidon HaSefer annual Torah knowledge competition |
| **Tanya** | Tanya study tracking and Bal Peh line counting |
| **Tehillim** | Tehillim (Psalms) marking for Shabbos Mevorchim |

If a menu item or feature is not visible, it may be because that module is not enabled for your base. Contact HQ if you believe it should be.

## Navigating the System

The main navigation menu is on the left side of the screen. Menu items are organized into sections:

- **Home** — your dashboard with quick links and widgets
- **Base Management** — soldiers, platoons, parents, staff, base settings
- **Missions** — mark, print, personalize, and report on missions
- **Rewards Program** — prizes, orders, achievement cards, miles
- **Chidon** — Chidon HaSefer competition management (if enabled)
- **Reports** — various printable and downloadable reports
- **Campaigns** — Tanya, Tehillim, Mivtzoim, and other special programs
- **Rebbe's Gift** — Tanya/Mishna lines and birthday gift campaign
- **Promotions** — medal ceremonies and rank promotions
- **Support** — open a help ticket

Some menu items are only visible to certain user types (e.g., "Modules" is HQ-only).

## The Home Page

After logging in, you land on the Home page. It shows:

- **Your base logo and name** at the top
- **Quick Links** — shortcuts to the most-used pages
- **Registration Widget** — shows how many soldiers are registered vs. unregistered for the current year
- **Resources** — links to helpful resources
- **Birthdays Widget** — upcoming soldier birthdays
- **Promotions Widget** — recent rank promotions

**If your account is new (BLANK type):** You will be prompted to choose between creating a new Base Commander account or accessing the Parent Portal.

## Common Actions Across the Platform

### Filtering Tables
Most list pages have column filters. Click the filter row below each column header to type or select a filter value.

### Downloading Data
Most list pages have a **Download (CSV/Excel)** button that exports the current table to a spreadsheet.

### Refreshing Data
Use the **Refresh** button on any page to reload the latest data from the server.

### Printing
Many pages are print-optimized. Use your browser's print function (Ctrl+P / Cmd+P). Most pages hide navigation and filter controls when printed. **For best print results, use Chrome or Firefox.** Edge and Internet Explorer may not display all elements (especially medals) correctly.
