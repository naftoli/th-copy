## TANYA

### Individual Marking — Edit Tanya/Mishna Lines (`/editSoldierLines2.php`)

**Access:** BC

**Purpose:** Review and correct the Tanya and Mishna memorized-line counts for each soldier, and sync the data to the Rebbe's Birthday Gift website (ourbirthdaygift.com).

### How It Works

- The system tracks how many lines of Tanya and Mishna each soldier has learned "Bal Peh" (by heart)
- Parents can also enter their child's counts through the parent portal
- This page lets you compare the two, correct as needed, and sync to the external birthday gift website

### What You See

At the top of the page: running school totals — total Tanya lines, total Mishna lines, and what has already been synced.

The table shows, per student:
| Column | Description |
|--------|-------------|
| Grade | Class/grade |
| Student | Name |
| Tanya Learned | The system's count of Tanya lines |
| Parent Entered (Tanya) | Count entered by the parent (read-only reference) |
| Mishna Learned | The system's count of Mishna lines |
| Parent Entered (Mishna) | Count entered by the parent (read-only reference) |
| Buttons | Calculate Mishna, Confirm & Sync |

### How to Use

1. **Select school** and **grade** (or all grades)
2. Review each student's counts — compare system counts to parent-entered values
3. If the parent-entered value is correct, use:
   - **"Copy Parent Entered to Tanya Learned"** — bulk copies parent Tanya values to the system field for all students
   - **"Copy Parent Entered to Mishna Learned"** — same for Mishna
4. Or edit individual student counts directly in the table
5. If a student learned Mishna by chapters (perakim), click **Calculate Mishna** to open a calculator that converts chapters to line counts
6. Click **Confirm & Sync** next to an individual student to save and sync that student to ourbirthdaygift.com
7. Or click **Confirm ALL** to sync all students in the school at once

> **Only registered soldiers** (or those with Tanya enrollment = on) appear in the list.

## TEHILLIM

### Mark Shabbos Mevorchim Tehillim (`/mark_tehillim2.php`)

**Access:** BC

**Purpose:** Record each soldier's Tehillim (Psalms) activity for every Shabbos Mevorchim — the Shabbos before each new Hebrew month.

### How It Works

Soldiers are assigned a Tehillim quota (number of chapters to recite each Shabbos Mevorchim). This page records their activity, and the system automatically marks the corresponding mission complete if a soldier meets their quota.

**Three things are tracked per student:**
1. **Kapitelach** — number of Psalms chapters recited
2. **Minutes** — time spent (max: 770 minutes per date)
3. **Shul** — whether the soldier attended synagogue (checkbox)

### How to Use

1. **Select school** and **grade** (or all grades)
2. **Select the Shabbos Mevorchim date** from the dropdown (one per Hebrew month)
3. For each student, enter their Kapitelach count, minutes, and check Shul attendance if applicable
4. Click **Save**
5. The system checks if each soldier met their quota and marks the mission complete automatically

> **Dates available:** One date per Hebrew month in the current year, for each Shabbos before a new month.
