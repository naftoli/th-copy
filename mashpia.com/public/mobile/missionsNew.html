Weekly Marking View

Please note that the "Weekly Marking View" is the only marking view available on desktops

  1. Each page starts on Friday and ends on Thursday
  2. Daily tasks start with Friday on the left for English and on the right for Yiddish and are laid out in one row.
  3. The parsha on the top of the page refers to the shabbos that occurs at the start of each weekly cycle.
  4. You can only go up to 3 weeks back. If you need to mark dates older then this please contact your Base Commander

Mission Printing

Please note that printing is only available on desktops

Please follow the instructions on the top of the printing page before printing out the mission sheets

Technical Support

If you encounter any issues that are technical in nature, please send an email to bugs@tzivoshashem.org with the following information:

  1. Your username
  2. Your child's serial number (found in the top left corner of their profile page).
  3. The marking date on which you are encountering this issue.
  4. A detailed and clear description of the issue.

Please note that it may take more than 24hrs for an investigation to occur and a response sent out.
