== Description ==

The ELEX Hide WooCommerce Shipping Methods Plugin is a free plugin allows you to hide certain shipping methods based on shipping class, order weight, other existing shipping methods, etc. You can hide WooCommerce default shipping methods as well as third-party shipping services from DHL, USPS, Stamps.com, UPS, FedEx, EasyPost, Australia Post, and so on.

= Features =
* Hide other shipping methods when "Free Shipping" is available.
* Hide Shipping Methods & Options based on Various Conditions.
* Hide Shipping Methods based on Shipping Classes.
* Hide Shipping Methods based on Weight of the items in cart.
* Hide Shipping Methods based on Other Shipping Methods.
